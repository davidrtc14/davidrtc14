### 🚀 Projetos em Destaque

#### 📦 [Estágio-App](https://github.com/davidrtc14/estagio-app)
*Aplicação Full-Stack com foco em processamento de arquivos e infraestrutura.*
* **Stack:** Node.js, Express, React, Docker, Nginx.
* **O que faz:** Integra um backend robusto com um frontend dinâmico. Utiliza bibliotecas para filtragem avançada de arquivos `.CSV` e geração dinâmica de documentos PDF e DOCX.
* **Destaque:** Todo o ambiente é conteinerizado com Docker, utilizando Nginx como proxy reverso para os serviços.

#### 🔐 [User-API](https://github.com/davidrtc14/user-api)
*API Back-end modular com foco em segurança e validação de dados.*
* **Stack:** NestJS, Prisma ORM, SQLite, JWT.
* **O que faz:** API estruturada com boas práticas, validação de DTOs (class-validator) e abstração de banco de dados via Prisma.
* **Destaque:** Implementação rigorosa de autenticação com JWT e hashing de dados sensíveis utilizando Bcrypt.
